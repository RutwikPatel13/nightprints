# Style guide

Notes from the "AI training - kids clothing prints" Pinterest board (75 pins, 7 sections). The board is a reference for prompt writing only. None of the pins go into training.

## What's on the board

| Section | Pins | Type | Look |
|---|---|---|---|
| Dino Clipart | 26 | placement | baby dinos, mix of watercolor, glossy cartoon and flat |
| Space Dinosaurs | 20 | both | saturated colors on dark navy, planets, rockets |
| heart | 9 | pattern | tiny hearts on white or cream, sparse |
| Construction vehicle patterns | 7 | pattern | diggers and trucks on yellow, teal, navy |
| Whale Seamless pattern | 4 | pattern | calm pale blues |
| cherry | 4 | pattern | red cherries and pink bows, coquette style |
| bow | 3 | pattern | small bows on muted grounds |

One "MINDSET" quote collage is saved in the board by mistake. Ignore it.

## Style families

The board mixes styles that would fight each other inside one LoRA. Split them:

- **dino**: Dino Clipart + Space Dinosaurs. Current focus.
- **sweet**: cherry + bow + heart. Next.
- **later**: whales, construction vehicles. Only if the friend wants them.

## Dino rules

- Chubby proportions, big eyes, no visible teeth.
- Clean dark outline, soft shading, no hard shadows.
- Pastel on light grounds, saturated on navy for the space variant.
- Patterns: motifs evenly spread, no motif cut off awkwardly, 8 colors max.
- No text anywhere in the art.

## Open questions for the friend

- What does the printer need? File type, DPI, tile size in inches or cm, color profile.
- Age range? Toddler prints usually run larger motifs than 6 to 10 year olds.
- Which ground colors sell best?
